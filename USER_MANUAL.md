# User Manual - Macrix Darts Application

## Overview
The Macrix Darts Application manages daily dart competitions, tracks player statistics, and maintains leaderboards.

## Getting Started

### 1. Language Selection
- Click the flag icon (🇬🇧/🇵🇱) in the top-right corner to switch between English and Polish.

### 2. User Roles
- **Admin**: Full access to manage players, assign roles, and run games.
- **Game Manager**: Can start new games, draw groups, and submit results.
- **User**: Can view the dashboard, leaderboard, game history, and their own profile.

### 3. Claiming Your Profile
- When you first log in, you may be prompted to claim your player profile.
- Select your name from the list to link your user account to your player stats.
- If your profile is already claimed or not found, contact an administrator.

## Features

### Dashboard
- View current leader, total players, and games played this month.
- Start a new game (Game Managers/Admins only).

### Players
- View a list of all players.
- Admins can add new players or remove existing ones.
- Link/unlink player profiles to user accounts.

### Leaderboard
- View the current standings for the month.
- Initial sorting is based on Rating (descending).
- Columns include Playe Name, Rating, Win-Loss Record, Average Score, and Matches Played.

### Game History
- View a list of all completed games for the current month.
- Admins can delete games if necessary.

### My Profile
- View your personal statistics: Games Played, Win Rate, Rating history.
- See a list of your recent games.

## Running a Game (Game Managers/Admins)

1. **Start New Game**: Go to the Dashboard or "New Game" tab.
2. **Select Players**: Check the box for each player present.
3. **Draw Groups**: The system will automatically generate random groups based on the number of players. You can also manually adjust groups if needed.
4. **Play**: Players compete in their assigned groups.
5. **Submit Results**: Enter the finishing position for each player (1st, 2nd, 3rd, etc.).
6. **Complete**: Once all groups are completed, the game is saved and stats are updated.
